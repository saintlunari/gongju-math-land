# 🏰 공주시 곱셈 땅따먹기 대작전 - 교사용 수업 안내서

> **초등학교 2학년 1학기 복습 [곱셈 개념] & 2학기 2단원 [곱셈구구] 연계 실시간 교실 게임**  
> 학생 20~25명이 각자의 태블릿/스마트폰으로 접속하여 공주시 16개 읍·면·동을 무대로 펼치는 신나는 실시간 땅따먹기 게임입니다.

---

## 🚀 빠른 시작 방법 (원클릭 실행)

1. **게임 실행**:
   - 폴더에 있는 `게임시작.bat` (또는 `start.bat`) 파일을 **더블클릭**합니다.
   - 2초 뒤 교사용 대형 전자칠판 화면(`http://localhost:3000/teacher.html`)이 자동으로 브라우저에 열립니다.

2. **학생 접속 안내**:
   - 교사용 화면 우측 상단에 표시되는 **대형 QR 코드**를 전자칠판/프로젝터에 띄웁니다.
   - 학생들은 태블릿(또는 크롬북, 스마트폰) 카메라로 **QR 코드를 비추면 즉시 게임에 접속**됩니다.
   - *(카메라가 없는 경우 화면에 적힌 주소, 예: `http://192.168.0.x:3000` 을 브라우저에 입력)*

---

## 🎮 게임 규칙 및 수업 진행 가이드

### 1단계: 프로필 설정 (1~2분)
- 학생들은 접속 후 **[이름/번호]**를 입력하고,
- 반 대항전 모드에서는 **[우리 반 (1반~4반)]**, 개인전 모드에서는 **[캐릭터 16종]**과 **[나만의 고유 색상 24색]**을 선택합니다.

### 2단계: 땅따먹기 본 게임 (10~15분)
1. **새로운 땅 차지하기 (빈 땅)**:
   - 가고 싶은 공주시 지역(정안면, 유구읍, 신관동 등)을 터치합니다.
   - 초등 2학년 맞춤형 **곱셈 5문제**가 출제됩니다.
   - 5문제를 모두 맞히면 그 땅이 **내 팀(반) 색깔로 물들고 깃발**이 꽂힙니다! (기본 방어막 🛡️1)

2. **내 땅 지키기 (방어막 강화)**:
   - 이미 차지한 내 땅을 다시 누르면 **"방어력 충전 모드"**가 됩니다.
   - 곱셈 3문제를 맞힐 때마다 방패 점수(🛡️)가 올라가 **최대 5단계까지 철벽 방어막**을 칠 수 있습니다.

3. **친구 땅 빼앗기 (공격전)**:
   - 다른 팀이 차지한 땅을 공격할 수 있습니다.
   - 곱셈 5문제를 맞힐 때마다 상대방의 방패(🛡️)를 1개씩 깎을 수 있습니다.
   - 방패가 1개 남은 상태에서 5문제를 맞히면 **땅을 빼앗아 우리 반 영토로 만듭니다!**
